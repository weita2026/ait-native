# Support

Choose the narrowest public route that matches the request:

- Ask usage and installation questions in
  [Q&A Discussions](https://github.com/weita2026/ait-native/discussions/categories/q-a).
- Propose product directions in
  [Ideas](https://github.com/weita2026/ait-native/discussions/categories/ideas).
- Share an AIT use case in
  [Show and tell](https://github.com/weita2026/ait-native/discussions/categories/show-and-tell).
- Report a reproducible bug or documentation correction through the
  [structured issue forms](https://github.com/weita2026/ait-native/issues/new/choose).
- Use the [installation guide](https://ait-native.dev/local-quickstart/) and
  installed-version instructions for published behavior. The
  [1.2.1 manuals](https://ait-native.dev/technical/1.2.1/) are planned
  documentation pending deployment and release readback.

Report undisclosed vulnerabilities only through
[private vulnerability reporting](https://github.com/weita2026/ait-native/security/advisories/new)
and follow [SECURITY.md](SECURITY.md). Never place credentials, tokens,
customer data, private prompts, or private filesystem paths in a public issue
or Discussion.

When asking for help, include the output of `ait --version`, the operating
system and architecture, the installation channel, the intended outcome, and
the smallest relevant reproduction. Community support is best effort and has
no guaranteed response time.
